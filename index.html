무엇인가

예전 프로그램(웹 그룹웨어와 델파이로 된 회계·인사급여)을 새로 지어 하나로 합친 업무 프로그램입니다. 화면 위 띠의 탭으로 세 프로그램을 오가고, 로그인은 한 번만 합니다. 화면 모양은 한 회사 프로그램처럼 같은 기준으로 맞췄습니다.

시험하는 법

  1. 아래 «시연 열기»를 누릅니다 — 따로 설치할 것도, GitHub 계정도 필요 없습니다.

    시연 열기 →

  2. 따로 받은 시연 계정으로 로그인합니다(로그인을 여러 번 틀리면 15분 동안 막힙니다).
  3. 화면 맨 위 띠의 «도움말»에 세 앱 사용 설명서와 점검 목록이 있습니다.
  4. 써 보다가 이상한 점은 시연 화면 맨 위 띠의 «결함 알리기»로 바로 보내 주세요 — GitHub 계정이 없어도 됩니다(운영자가 받아 정리합니다).

시연 데이터는 이름·주민번호·사업자번호·주소·전화·계좌를 가린 사본입니다. 마음껏 넣고 고치고 지워도 됩니다(망가지면 처음 상태로 되돌립니다).

먼저 보면 좋은 것

1순위사람 손으로만 알 수 있는 것 — 결재 문서 편집기에 한글 입력·엑셀·워드·한글(HWP)에서 표 복사해 붙여넣기, 표에서 Enter 로 칸 이동, 브라우저·확대 배율·좁은 창
2순위업무 흐름 — 결재 상신 → 승인·반려, 전표 → 장부, 근태 → 급여 반영, 출력 미리보기·PDF
3순위모양과 속도 — 숫자 정렬·쉼표, 글자 잘림, 화면 여는 속도

알려진 한계

  • 전자세금계산서 실제 발행·국세청 실제 신고는 하지 않습니다(신고 파일 만들기까지).
  • 은행·메일·바깥 시스템으로 보내는 단추 일부는 «연동 요청함»에 쌓기만 합니다.
  • 시연 서버는 운영자 PC에서 돕니다. 그 PC가 꺼져 있으면 접속되지 않습니다.
소스는 공개하지 않습니다. 시연 계정은 따로 받은 사람만 씁니다.
